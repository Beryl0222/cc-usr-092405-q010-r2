# 二手烟负担证据计算

维护文献、调查、指标定义、地区映射、风险参数与疾病负担结果之间，
**每个数字都能找到输入与公式版本**的可复算依赖链。

`fixtures/domain.json` 保存首批领域名词和状态样例；领域语义由
`domain/` 包实现，业务记录只能经正式接口产生。

## 运行

```bash
python3 service.py --check   # 基础配置检查
npm test                     # 服务契约 + 领域契约 + 情景契约（共 36 项）
python3 -m compileall -q .   # 编译检查全部 Python 模块
```

## 分层

| 模块 | 职责 |
| --- | --- |
| `domain/registry.py` | 证据登记处：版本快照、重复合并、竞争声明与裁定、撤回（不删除） |
| `domain/engine.py` | 版本化公式（PAF→归因死亡）、缺失年显式估算、依赖指纹与增量重算 |
| `domain/publisher.py` | 不可变报告、按性别/儿童年龄段/疾病拆分、最小样本披露、撤回影响通告、原样复现 |
| `domain/scenario.py` | 情景分析：报告快照派生、三类带来源调整、版本链增量重算、复核工作流、对比摘要与重放、失效标记、日志恢复 |
| `domain_contract.py` | 覆盖完整生命周期的契约测试（3 国 / 4 病 / 3 年 / 性别 / 年龄段样例） |
| `scenario_contract.py` | 情景层契约测试：调整约束、增量重算、规则沿用、并行编辑复核、对比与重放、失效与重启一致 |

## 关键规则如何落地

- **只追加，不覆盖**：原始数据更正产生 `record@v2`，旧版置「已替代」但保留，
  仍可按 id 取回更正前数值。
- **重复导入合并**：`kind + source_id + 内容哈希` 一致时只记一次 `merge`，不新增版本。
- **冲突保留竞争**：不同来源对同一槽位取值不一致时双方都保留为竞争声明，
  槽位为「待裁定」，引擎对相关单元产出 `conflict` 而非数字；裁定后落败方仍可追溯。
- **缺失年不冒充观测**：观测年标 `observed`；无观测年按运行配置的方法
  （线性插值 / 临近结转，含 `max_gap` 年限）补值并标 `estimated`，记录锚点观测
  快照；无支撑则 `no_input`，不产出数字。
- **增量重算**：每个单元的依赖快照集合 + 冻结输入 + 公式流水线哈希为指纹；
  迟到调查只改变依赖它的单元，风险参数撤回只使依赖分支变 `void`（并记录失效
  参数快照），其余单元沿用上一轮结果。
- **发布即冻结**：报告完整复制当次单元（取值、95% UI、输入、依赖快照、公式
  版本、观测/估算构成与口径年份），此后登记处变化不影响报告；头条数字默认只
  汇总口径年份，并按性别、年龄段（儿童 `0-4`/`5-14` 单列）、疾病拆分。
- **最小样本披露**：支撑调查 `n < 阈值` 的单元抑制（发布件不含数字），
  且不进入任何汇总。
- **撤回不删报告**：论文/参数撤回只向报告追加影响通告，列出受影响单元与结论；
  正文数字不变，旧报告可用冻结输入与公式版本 `reproduce()` 原样复算。
- **可追溯**：任意数字 → `inputs`（暴露率、RR、死亡基数及各自 UI）→
  `dependency_snapshots`（证据版本）→ `formula_version`（`shs_burden-v1`）。
- **情景派生不污染发布结论**：情景以冻结报告为基底，只调整有 `source`
  来源说明的三类参数（暴露比例 / 相对风险选择 / 归因窗口）；引用登记处
  快照时校验取值一致；每次调整形成新版本，单元指纹 = 基底指纹 + 命中
  调整链，只重算依赖变化的分支；缺失年估算、未裁定冲突、小样本抑制在
  情景中原样沿用，调整不复活无输入/冲突/抑制单元。
- **并行编辑与角色复核**：同一父版本可并行起草；提交后须「审核人」角色
  且非作者本人复核；同一父版本至多一个批准分支，落选版本打 `conflict`
  失效标记；只有「已批准且未失效」的版本进入对比摘要，原报告与其他
  情景始终不可变。
- **对比可重放、失效可见、重启一致**：对比摘要同时给出与基底报告的
  差值、输入谱系（调整链 + 证据快照 + 公式版本）与不确定性来源分解；
  任意版本可 `replay()` 重放且结果一致；调整来源被撤回时版本（含下游
  链）打 `invalidated` 失效标记；全部状态变更记入只追加日志，服务重启
  后 `restore()` 重放的对比结果与失效标记逐字节一致。

样例运行的头条口径：2022 年全球二手烟归因死亡约 **171 万**
（95% UI 约 58 万–302 万），其中 64 个观测单元、16 个估算单元。
